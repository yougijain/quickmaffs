# iOS (Capacitor)

This folder is the native iOS wrapper generated by Capacitor. The web app in
`../src` is the source of truth; the native shell just hosts it in a WKWebView.

Everything up to `cap sync` runs on Linux. The steps below require **macOS +
Xcode** and cannot be done in the web/CI environment.

## One-time setup (Mac)

```bash
npm install
sudo gem install cocoapods      # if not already installed
npm run build                   # produce dist/
npx cap sync ios                # copy web assets + run pod install
npx cap open ios                # open App.xcworkspace in Xcode
```

In Xcode: select the `App` target → **Signing & Capabilities** → pick your team
(sets a provisioning profile), then run on a simulator or device.

## Iterating

After any web change:

```bash
npm run build && npx cap sync ios   # or: npm run cap:sync
```

## Icons & splash (Mac)

Generate native icon/splash sets from a source image:

```bash
npm i -D @capacitor/assets
npx capacitor-assets generate --ios
```

## App Store

Set version/build in Xcode, archive (Product → Archive), and upload via the
Organizer. `appId` is `com.quickmaffs.app` (see `../capacitor.config.ts`).

## Notes

- `App/App/public/` is the copied web build and is git-ignored — it is
  regenerated by `cap sync`.
- `App/Pods/` is git-ignored; run `pod install` (via `cap sync`) on the Mac.
